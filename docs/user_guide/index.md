# User Guide

Welcome to the **de-dup User Guide**. This guide helps you set up, configure, and get the most out of de-dup for deduplicating your files, photos, and music library.

---

## Guide Topics

* **[Quick Start & Installation](quickstart.md)**
  Install dependencies, build native binaries, and launch de-dup on Linux, macOS, or Windows.
* **[HTML Web Console](web_console.md)**
  Use the responsive Web Console for browser-based, headless, or server execution.
* **[Scanning Modes & Algorithms](scan_modes.md)**
  Learn how Standard File, Music, and Picture scan modes analyze content.
* **[Database & Caching](caching_and_database.md)**
  Understand how SQLite and Valkey/Redis cache database scanning progress and allow instant resumption.
* **[FAQ & Troubleshooting](faq.md)**
  Solutions for common questions and runtime scenarios.
